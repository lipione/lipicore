## Recommended Commercial Structure

LipiCore Bank Staff AI Appliance powered by LipiLLM will be provided as a managed hosted package on Silver Lining server infrastructure, with staff access delivered through LipiCore Desktop software for Windows and macOS. The upgraded product includes LipiLLM, Lipi One's private Nepal-context fine-tuned LLM layer, approved-knowledge Q&A, document intelligence, OCR Extraction, Compliance Workspace, Model Lab, RAG Evaluation, source passage inspection, clause/page policy citation metadata, adaptive ingestion, multilingual retrieval, queued long-document analysis, bank-readiness checks, internal staff chat, and optional internal banking workspaces controlled by Super Admin feature flags. Sanima Bank will pay separately for:

1. **One-time setup:** implementation, configuration, onboarding, initial document setup, training, and go-live support.
2. **Monthly server / infrastructure:** hosted server capacity, AI runtime, storage, backup, monitoring, network, and operational management.
3. **Monthly software license + support:** LipiCore application license, LipiLLM model layer, Windows/macOS desktop software access, updates, security patches, support, and platform maintenance.

All pricing below is indicative in **NPR** and exclusive of VAT, withholding, and applicable taxes.

## Market Comparison

Public ChatGPT and Claude prices are useful benchmarks, but they are general-purpose AI workspaces rather than a managed bank staff AI appliance with LipiLLM Nepal-context model routing, desktop delivery, hosted infrastructure, adaptive document ingestion, multilingual retrieval, OCR extraction and repair, queued long-document analysis, clause/page source citations and passage review, RAG evaluation gates, readiness checks, RBAC, audit records, internal banking workspaces, internal chat, model evaluation tooling, and support.

| Option | Indicative Cost | Key Tradeoff |
|---|---:|---|
| LipiCore Starter | NPR 400,000/month for 200-500 users | Approx. NPR 2,000 to NPR 800 per user/month |
| LipiCore Standard | NPR 800,000/month for 1,000-2,000 users | Approx. NPR 800 to NPR 400 per user/month |
| LipiCore Enterprise | NPR 1,600,000/month for 3,000-5,000 users | Approx. NPR 533 to NPR 320 per user/month |
| ChatGPT / Claude workspace | Around USD 25/user/month monthly | Around NPR 3,825 per user/month before Nepal-context fine-tuning, custom banking platform, RAG, audit workflow, hosted infrastructure, desktop packaging, and support |

At 2,000 users, a USD 25/user/month AI workspace is approximately USD 50,000/month, or around NPR 76.5 lakh/month at an indicative NPR 153.00/USD exchange rate checked on June 1, 2026. LipiCore Enterprise covers 3,000-5,000 users at NPR 16 lakh/month with the managed banking platform included.

## Internal Chat System Bonus Module

The internal chat system is included as a bonus module at no additional software license charge. It provides staff-to-staff and group communication inside the secured LipiCore environment, using the same bank-scoped user base and administrative controls.

Messenger boundary: chat messages and shared files are not embedded into the document intelligence index, not used as AI context, and not used to train public AI models unless a future written scope explicitly changes that boundary.

Included features:

- Direct staff conversations.
- Department channels and custom group conversations.
- Announcement channels.
- Secure file and image sharing, subject to retention and attachment policy.
- Unread counters, delivery status, and read status.
- Local keyword search over permitted conversation history.
- Role-aware access aligned with configured LipiCore users.
- Activity records suitable for administrative review.
- Hosted storage and backup under the managed environment.
